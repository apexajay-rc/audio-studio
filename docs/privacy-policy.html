Privacy Policy

Universal Tab Audio Studio is a browser extension that captures audio from the browser tab the user explicitly selects, applies audio effects locally, and lets the user export the processed recording.

Effective date: 26 November 2026

Information the extension accesses

  • Selected tab metadata: after the user clicks the extension toolbar button, the extension reads that tab's identifier, title, and URL hostname to identify the source in the Studio interface and establish the capture session.
  • Selected tab audio: after that explicit user action, Chrome's tabCapture API provides the tab's audio stream. The extension processes the stream in the browser using the Web Audio API.
  • Temporary session state: the extension temporarily stores the capture handoff token, tab identifiers, source title, and hostname in Chrome's session storage so the background service worker can hand the stream to the Studio page and clean up the session.
  • Playback settings: speed and pitch settings are applied to supported HTML audio/video elements in the selected tab. The original playback settings are held in page memory so they can be restored.

How information is used

The information above is used only to capture the tab selected by the user, label that source in the Studio interface, apply audio effects, maintain the active capture session, and restore supported media playback settings when capture ends.

Local processing and exported files

Audio capture, effects processing, and recording occur locally in the browser. Audio is held in memory while it is processed and recorded. When the user selects an export action, the extension creates a file locally and asks the browser to download it to the user's chosen/default download location.

The extension does not upload captured audio, recordings, tab titles, hostnames, or exported files to a developer-controlled server.

Sharing, analytics, and tracking

The extension does not operate an analytics or advertising service, does not use tracking cookies, and does not share the accessed tab metadata or audio with the developer or other third parties. It makes no network requests as part of its audio-processing functionality.

Retention and deletion

Temporary capture data is held in Chrome session storage and in browser memory for the active session. The extension removes session entries when the Studio tab closes. Browser session storage is cleared by Chrome when the browser session ends. Exported files are under the user's control and can be deleted using the operating system's normal file-management tools.

User control

Capture starts only after the user invokes the extension from the source tab. The user can stop capture or close the Studio tab to end the capture session. The extension does not attempt to bypass DRM, authentication, or other access controls. Whether a particular source is capturable depends on Chrome and the source page.
