# Reference and attribution

This extension is an independent implementation built around Chrome's documented `tabCapture` API and Web Audio API. It does not contain copied source files from the Slowed & Reverb extension.

The effect set and browser-extension workflow were informed by reviewing [Slowed & Reverb by Ozan Sahin](https://github.com/sahinozan/slowed-and-reverb), whose repository is published under the MIT License. No source code from that repository is included in this package.

Chrome API reference: https://developer.chrome.com/docs/extensions/reference/api/tabCapture/
